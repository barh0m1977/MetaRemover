# MetaRemover

---

## 📱 Overview

**MetaRemover** is a cross-platform application built with **Kotlin Multiplatform** and **Compose Multiplatform** that allows users to remove metadata (EXIF and other embedded information) from images before sharing them.

Many images contain hidden information such as:

- 📍 GPS Location
- 📷 Camera Model
- 📅 Date & Time
- 📸 Camera Settings
- 👤 Device Information
- 🏷️ Other EXIF Metadata

MetaRemover helps protect your privacy by exporting a clean image without unnecessary metadata while keeping the visual quality intact.

---

## ✨ Features

- Remove EXIF metadata
- Preserve image quality
- Simple and modern UI
- Cross-platform support
- Fast image processing
- Save cleaned images to gallery
- Privacy-focused
- Lightweight application

## 🔒 Privacy

MetaRemover processes images locally on your device.

- No images are uploaded.
- No metadata is stored.
- No analytics.
- No cloud processing.

Everything happens completely offline.

## 🛠 How It Works

1. Select an image.
2. The application loads the image into memory.
3. A new image is generated without copying metadata.
4. The cleaned image is saved to your gallery.
5. Share the clean image safely.
