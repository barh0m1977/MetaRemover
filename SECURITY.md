# Security Policy

## Supported Versions

This project is actively maintained. Security updates are applied to the latest stable version.

| Version              | Supported |
| -------------------- | --------- |
| latest (main branch) | ✅         |
| older releases       | ❌         |

---

## Reporting a Vulnerability

If you discover a security vulnerability in **MetaRemover**, please report it responsibly.

### 📩 How to report

Send details to:

* GitHub Issues (preferred for non-sensitive reports):
  https://github.com/barh0m1977/MetaRemover/issues

---

### 📌 What to include

Please provide:

* Description of the issue
* Steps to reproduce
* Affected platform (Android / iOS)
* Screenshots or logs if available

---

### ⏱ Response time

* Initial response: within 48–72 hours
* Status update: after validation
* Fix timeline: depends on severity (critical issues prioritized)

---

### 🔒 Policy

* Security reports are handled confidentially
* No public disclosure until a fix is available
* Contributors may be credited if desired

---

Thank you for helping keep MetaRemover secure.
